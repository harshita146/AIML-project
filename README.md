# AI Health Assistant System

##  Project Overview

The *AI Health Assistant System* is a rule-based artificial intelligence application developed using Python. This system analyzes user health data such as age, weight, height, gender, and activity level to generate a personalized nutrition and health report.

It simulates intelligent decision-making by providing customized recommendations, calorie targets, and health insights based on the user's Body Mass Index (BMI) and lifestyle.

## Objectives

* To calculate BMI and determine health category
* To provide personalized nutrition recommendations
* To generate AI-based health suggestions
* To recommend calorei gain or loss plans
* To simulate an AI-based decision-making system

## Features

### Basic Health Report

* BMI calculation and classiffication
* Ideal weight estimation
* Macronutrient requirements (Protein, Carbs, Fats)
* Daily calorie requirement
* Water intake recomendation
* Sleep duration suggestion
* Vitamins and minerals recommendation

### AI-Based Features

* AI Health Score calculation
* Personalized diet and workout plans
* Weight gain plan for underweight users
* Weight loss plan for overweight users
* Maintenance plan for normal users
* Calorie surplus and deficit targets
* Health risk prediction and insights

## AI Concept Used

This project is based on a **Rule-Based AI System**.

The system uses conditional logic (if-else statements) to:

* Analyse user inputs
* Classify health conditions
* Generate intelligent recommendations

This simulates artificial intelligence by mimicking decision-making behavior.

## Technologies Used

* Python (Core Programming Language)
* Basic Input/Output Operations
* Conditional Statements (if-elif-else)
* Mathematical Calculations

## Input Parameters
The system takes the following inputs from the user:
* Name
* Age
* Weight (kg)
* Height (meters)
* Gender (M/F/O)
* Activity Level (sedentary/moderate/active/athlete)

##Output
The system generates:
* Complete health and nutrition report
* AI-based personalized recommendations
* Workout or diet plan
* Calorie gain or burn targets
* Health score and risk analysis

## Conclusion
This project demonstrates how artificial intelligence concepts can be implemented using rule-based logic. The system adapts its output based on user data, making it an intelligent and interactive health assistant.

Although it does not use machine learning, it effectively simulates AI behavior through decision-making and personalized recommendations.
